Procedure: Change Beneficiary Designations (chat)

Section: Beneficiaries · Page ID: update-beneficiaries-task

Step-by-step chat procedure for adding, updating, or removing an IRA beneficiary, the fields collected, and the checks before approval.

What the task collects

FieldOptions or format
AccountThe IRA to update (asked if more than one)
ActionAdd, Update, Remove
Beneficiary nameFull legal name
RelationshipSpouse, child, sibling, parent, etc. (not asked for Remove)
PercentageShare of the account (not asked for Remove)
Primary or secondaryPrimary or Secondary (not asked for Remove)

Scope

The chat task changes beneficiaries on IRA accounts. For a taxable account, see Transfer on death (TOD) for taxable accounts: the client can do it online. Do not refer the client to "the support team" for a taxable-account TOD request; you are the support team. Guide them to My Account → Beneficiaries or the TOD form.

Procedure

  1. Confirm the account. Each IRA has its own designations.
  2. Show (or ask about) the current beneficiaries so the result is clear.
  3. Let the task expert collect the details.
  4. Check the percentages: after the change, primaries must total 100% and secondaries must total 100%. If adding a beneficiary, ask how existing percentages change. The final designation replaces the old one.
  5. Check spousal consent for married clients in community property states naming a non-spouse. See Spousal consent.
  6. Recap the complete resulting designation and get clear confirmation.
  7. Review the Proposed Action: account, name spelling, relationship, percentage, level. Use the locate buttons.
  8. Submit. The change takes effect immediately; the client receives a confirmation and a security alert.

Sensitivity

Beneficiary conversations often follow a death, divorce, or diagnosis. Be warm and unhurried. Watch for exploitation: a new acquaintance replacing family as beneficiary, especially with someone else present in the conversation, warrants care. See Elder financial exploitation and vulnerable clients.

Removing the last beneficiary

If the client removes all primary beneficiaries, contingent beneficiaries (if any) become primary in effect, or the account defaults to the spouse or estate. Point this out.
