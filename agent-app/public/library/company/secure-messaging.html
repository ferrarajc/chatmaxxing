Secure messages

Section: Company & Contact Directory · Page ID: secure-messaging

How clients send secure messages and documents, response times, and when to recommend a secure message over chat.

On this page

  • What it is
  • Response times
  • When to recommend it
  • Limits
  • Example uses
  • What agents see
  • Security

What it is

Secure messaging lets authenticated clients send a message to Client Services from My Account → Messages. Messages are encrypted and stored in the client's message center. Clients can attach documents (PDF, JPG, or PNG, up to 10 MB each).

Response times

  • Standard requests: within 1 business day.
  • Complex account issues: within 3 business days.
  • Clients receive an email notification when a reply is waiting; the reply itself is only in the secure message center.

When to recommend it

  • The client needs to send a document (a trust certification, a death certificate copy, a divorce decree).
  • The request needs research that will take longer than a chat.
  • The client wants a written record of the answer.

Limits

Secure messages are not for urgent matters. Fraud reports, locked-out clients, and time-sensitive trades should use chat or phone. We never ask for passwords by secure message.

Example uses

  • Sending a copy of a divorce decree for an IRA transfer.
  • Asking for a cost basis history that requires research.
  • Following up on an open request with a written trail.

What agents see

Secure messages arrive in a separate service queue. If a client mentions in chat that they sent a secure message, you can check whether it has been answered and summarize the reply.

Security

Clients should never email documents to staff. Secure messaging and the document upload page are the safe channels.
