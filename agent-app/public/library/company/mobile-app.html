The mobile app

Section: Company & Contact Directory · Page ID: mobile-app

What clients can do in the Bob's Mutual Funds mobile app and common app issues.

On this page

  • Features
  • Common issues
  • Signing in
  • Mobile check deposit

Features

The mobile app (iOS and Android) supports viewing balances and holdings, buying, selling, and exchanging funds, managing automatic investments, depositing by ACH, viewing statements and tax documents, secure messages, chat, and sign-in approvals for 2FA. Account opening, beneficiary changes, and some forms are best done in the web portal.

Common issues

IssueSuggestion
App won't open or crashesUpdate to the latest version; restart the device
Biometric sign-in stopped workingSign in with password once; re-enable Face ID / fingerprint in app settings
Not receiving sign-in approval promptsCheck notification permissions; ensure the device is still trusted
Balances look different from the websitePull to refresh; values update after each day's NAV

If an issue persists, collect the device type, app version, and a description, and log it as a Technical Issue. See Chat and workspace technical problems.

Signing in

The app supports biometric sign-in (Face ID, fingerprint) after the first password sign-in. The device must be a trusted device. If the client gets a new phone, they sign in with their password and 2FA on the new device, then enable biometrics.

Mobile check deposit

Checks up to $50,000 can be deposited in the app by photographing both sides. Endorse with the signature and "For mobile deposit to Bob's Mutual Funds only". Keep the paper check for 14 days, then destroy it. See Checks we receive.

Notifications

Push notifications can be enabled for trade confirmations, deposits, and security alerts in the app's settings.
