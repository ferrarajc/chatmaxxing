When the library doesn't have the answer

Section: Start Here · Page ID: when-you-cannot-find-it

How to handle a question the library does not answer, how to escalate it, and how to report the gap.

On this page

  • In the chat
  • After the chat
  • Reporting an error

In the chat

If you have searched the library and asked the library's question box and still have no reliable answer:

  1. Tell the client you are confirming the answer rather than guessing. "That's a good question. I want to give you an exact answer, so let me confirm it."
  2. Ask your team lead or the agent help channel. Give the client a time estimate and keep the response timer moving.
  3. If no one can answer within a few minutes, offer a callback or a follow-up secure message with a specific timeframe. See Scheduling callbacks.
  4. If the question needs a specialist (estate, licensed brokerage, retirement specialist), route it. See Routing to specialist teams.

Never invent a policy, a deadline, or a fee. It is far better to say "I'll confirm and get back to you by tomorrow afternoon" than to give an answer that later proves wrong.

After the chat

Report the gap so the library improves. Include:

  • The client's question in their words (no personal information).
  • What you searched for and which pages you checked (use Page IDs).
  • The answer, once you have it, and its source.

Content owners prioritize gaps reported by more than one agent and anything involving money movement, deadlines, or taxes.

Reporting an error

If a page is wrong, report it the same way and mark it urgent if the error could cause a client to lose money, miss a deadline, or receive incorrect tax treatment. Until the page is corrected, your team lead's written guidance takes precedence.
