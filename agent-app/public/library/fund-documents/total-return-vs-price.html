Total return versus price change

Section: Fund Documents & Performance · Page ID: total-return-vs-price

Why a fund's price change understates its return, especially for funds that distribute a lot.

On this page

  • The difference
  • Example
  • Client questions
  • Stock funds too
  • Where to see total return

The difference

A fund's NAV change ignores distributions. When a fund pays a distribution, its NAV drops by that amount. So:

  • Price return = change in NAV only.
  • Total return = change in NAV plus distributions reinvested.

For bond funds, which pay out most of their return as income, price return can be near zero or negative while total return is positive.

Example

BFBI's NAV starts the year at $98.30 and ends at $98.10 (price return about −0.2%). It paid about $2.10 per share in monthly dividends during the year. Its total return is about +1.9%.

Client questions

"My bond fund price hasn't moved in years."

Explain that bond funds pay their return mostly as monthly dividends; with reinvestment on, the client owns more shares over time.

"The chart shows a drop but the return is positive."

The chart may show NAV only. Check the total-return figures.

Stock funds too

Stock funds that pay larger dividends (BFHDY, BFUTL) also show a noticeable gap between price return and total return. Growth funds (BFGR) pay small dividends, so the gap is small.

Where to see total return

Fund profile return tables and the Research page's performance tab show total returns. Price charts show NAV only unless the "include distributions" option is selected.
