Prior-year contributions (January to April)

Section: IRA Contributions · Page ID: prior-year-contributions

How to make and record a contribution for the previous tax year during the overlap period, and how to correct a wrong year.

On this page

  • The overlap period
  • Contributions summary
  • Correcting the year
  • Automatic investments

The overlap period

From January 1 to April 15, a client can contribute for either the current year or the prior year. Every contribution in that window must be designated:

  • Online, the purchase screen asks "Tax year" for IRA contributions during the overlap.
  • In chat, ask the client which year before approving the Proposed Action, and record it.
  • By check or wire, the client writes the year in the note or reference.

If no year is designated, the contribution is recorded for the current year.

Contributions summary

From January to April, the contributions summary shows both years, so you can see the remaining room for each. After April 15 it shows only the current year.

Correcting the year

If a contribution was recorded for the wrong year, it can be recoded if the client asks before the prior-year deadline (or, if the mistake was ours, later). Route the request to Retirement Specialists or Account Services with the transaction details. Recoding changes the client's Form 5498. See Correcting errors (as-of trades).

Automatic investments

Automatic investments during January–April always count for the current year. See Automatic investing in IRAs.
