Procedure: Update Security Settings

Section: Identity, Privacy & Security · Page ID: update-security-task

Chat procedure for password changes, enabling 2FA, changing 2FA methods, and removing trusted devices.

On this page

  • What the task collects
  • Procedure
  • Things to watch for

What the task collects

FieldOptions
What to updateChange password; Enable 2FA; Disable 2FA (processed as a method change); Remove trusted device

Procedure

  1. Confirm the client is authenticated and the request is coming from the owner. Security changes are high risk; if anything seems off, re-verify. See Verifying client identity.
  2. Let the task expert collect the action, or choose it from the task menu.
  3. Review the Proposed Action and submit.
  4. Explain what happens next:

- Change password: a secure link is sent to the email on file; the client sets the new password themselves. We never see it. - Enable 2FA: the client completes setup at My Account → Security (scan a QR code or verify a phone number). - Disable 2FA: 2FA is required, so explain that we can switch the method rather than remove it, and guide them to My Account → Security. - Remove trusted device: the device must complete 2FA on its next sign-in.

Things to watch for

  • A request to change security settings immediately before or after a request to change contact details or move money is a fraud signal. Pause and verify.
  • If a client says they are locked out, they are not authenticated, so they cannot use this task. Direct them to Password resets or Locked accounts.
