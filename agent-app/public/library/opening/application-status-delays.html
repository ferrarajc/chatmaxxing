Application status and delays

Section: Opening Accounts · Page ID: application-status-delays

How to check an application's status and the common reasons applications are held.

On this page

  • Checking status
  • Common reasons for delay
  • Declined applications

Checking status

Applicants can see their application status by signing in with the credentials they created. Statuses:

StatusMeaning
SubmittedReceived; automated checks running
Action neededWe need documents or a signature from the applicant (or a joint owner)
Under reviewAccount Services is reviewing documents
ApprovedThe account is open; funding can proceed
DeclinedWe were unable to open the account

Common reasons for delay

  • Identity verification needs documents. See Identity verification for new accounts (CIP).
  • A joint owner has not signed.
  • Trust documents are incomplete or the trustee names don't match.
  • The applicant reported affiliation with a brokerage firm, which requires a letter from their employer's compliance department.
  • The residential address is a PO Box or commercial mail drop.
  • The applicant is on a sanctions or watch list match that must be cleared (we cannot tell the applicant this). See Sanctions screening (OFAC).

Declined applications

If an application is declined, the applicant receives a letter. Agents cannot discuss reasons that relate to AML or sanctions screening. For other reasons (incomplete information), help the applicant reapply.
