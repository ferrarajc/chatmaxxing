Reference numbers

Section: Troubleshooting · Page ID: reference-numbers

What reference numbers are, where clients find them, and how to use them to trace an action.

On this page

  • Format
  • Using them
  • If the client lost it
  • Where the number appears
  • Quoting them
  • When a client calls about an action

Format

Every action submitted through the chat Proposed Action flow returns a reference number in the format REF-XXXXXX. It appears on the green confirmation card in the client's chat, in the transcript, and in the after-chat summary.

Using them

  • A client referring back to a chat action can quote the reference number; search the client's transcripts or recent activity for it.
  • Include reference numbers in escalations and complaint records.
  • Trade confirmations carry their own confirmation numbers, which may differ from the chat reference number.

If the client lost it

Find the chat in the client's transcript history (the client can see their last 3 months of live-agent chats in the chat menu) or locate the transaction by date and amount.

Where the number appears

PlaceWhat it shows
Client's chatThe green confirmation card
Client's chat historyThe transcript, for 3 months
Agent workspaceThe Proposed Action result and transcript
After-chat summaryIncluded by the ACW generator

Quoting them

Read the full reference number to the client in your closing message for any completed action, so they have it even if they don't save the transcript. See Closing a chat.

When a client calls about an action

Ask for the reference number first; it is the fastest way to find the exact action. If they don't have it, the date, account, and amount are usually enough.
