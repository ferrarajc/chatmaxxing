Chat and workspace technical problems

Section: Troubleshooting · Page ID: chat-technical-issues

Problems clients and agents have with chat itself, and how to recover.

On this page

  • Client side
  • Agent side
  • Example

Client side

ProblemFix
Messages not sendingCheck connection; reload the page (the chat resumes)
Chat disappeared after navigatingChat persists per browser tab; returning to the site in the same tab resumes it. A new tab starts a new chat
Can't find the chatIt may be minimized to the bar at the bottom of the screen
Card "Your approval is required" not visibleScroll down in the chat; reload if needed
Transcript download didn't workAllow downloads for the site; the chat history menu also has transcripts for 3 months

Agent side

ProblemFix
Workspace disconnected bannerRefresh; chats reattach
AI suggestions not loadingContinue manually; suggestions resume when the service recovers
Autopilot stopped with an errorRead the note, resume when ready, or continue manually
Proposed Action failedCheck whether it partially completed before retrying. See The Proposed Action card

Report persistent issues with the build stamp from the browser console. See The agent workspace at a glance.

Example

Client: "My chat keeps disappearing when I go to another page."

Agent: "The chat stays with your browser tab. If you open a page in a new tab, it starts fresh. Navigate within the same tab and our conversation will stay right here, and you can minimize it to the bar at the bottom of your screen."
