The phone callback console

Section: Agent Workspace & Tools · Page ID: phone-callback-console

What phone agents see when they handle a scheduled callback, for chat agents who set callbacks up.

On this page

  • Purpose
  • The dossier
  • Helping the phone agent
  • What chat agents should include

Purpose

The callback console is the workspace for agents who make scheduled outbound calls. Chat agents do not use it directly, but understanding it helps you set up callbacks well.

The dossier

For each scheduled callback, the system researches the client's request and builds a dossier:

  • The intent: a summary of the client's underlying goal, taken from the real chat that led to the callback.
  • A worked answer with findings and any gaps that need confirmation.
  • Coaching for the call.
  • An editable guided script with branches for likely responses.
  • The originating transcript, with the key passages highlighted.
  • A client snapshot: accounts, balances, and recent performance.

Helping the phone agent

The better the chat that leads to a callback, the better the dossier. Before scheduling, make sure the chat states clearly what the client wants ("Client wants to discuss whether to convert part of her Traditional IRA to Roth this year; she has questions about the tax impact") and any facts you have already confirmed. Promise the client only what the callback can deliver.

What chat agents should include

  • Any facts already verified with the client.
  • The client's preferred callback number and best times.
  • Sensitivities (recent bereavement, hearing difficulty, preference for Spanish).

Example dossier intent

"Client wants to discuss whether to convert part of her $310,000 Traditional IRA to Roth before retiring in 2027; concerned about tax bracket and Medicare premiums."
