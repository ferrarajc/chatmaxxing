Choosing a code

Choose the single most specific code that describes the primary reason for the chat. If a client asked a quick balance question and then changed beneficiaries, the code is Beneficiary Change. The summary records secondary topics.

Complaint versus grievance

Use Complaint Filed only when a complaint was logged following Handling complaints. A client who is unhappy but does not want to file a complaint is a Grievance. When unsure, log the complaint; under-recording complaints is a compliance failure.
