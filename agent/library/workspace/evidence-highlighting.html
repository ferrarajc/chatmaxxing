Evidence highlighting

Section: Agent Workspace & Tools · Page ID: evidence-highlighting

How the transcript highlights show where each Proposed Action value came from, and what "not located in transcript" means.

On this page

  • How it works
  • "Not located in transcript"
  • Why it matters

How it works

When a Proposed Action card is showing, the transcript highlights the exact words where each value was established: either the client's own statement ("put $2,000 into the 500 index fund") or an agent recap that the client explicitly confirmed. Later echoes ("great, the $2,000 is all set") are not used as evidence.

Each field on the card has a locate button (⌖). Clicking it scrolls the transcript to that field's highlighted span and flashes it.

"Not located in transcript"

If a field shows "not located in transcript", the system could not find where that value came from. This is a signal to scrutinize the field. Common reasons:

  • The value was inferred from the profile (for example, the only account the client has) rather than stated. That may be fine; confirm it with the client.
  • The client gave the value in an unusual form ("two grand") that the locator could not match. Confirm the exact amount.
  • The value is wrong. Correct it on the card and reconfirm with the client.

If the highlighting service is unavailable, the card simply shows no highlights. Review the transcript manually.

Why it matters

Most service errors are transcription errors: the wrong fund, the wrong account, an extra zero. Evidence highlighting lets you verify each value in seconds. Use it on every card.
