Exchanges overview

Section: Exchanges · Page ID: exchanges-overview

What an exchange is, how it is priced, what it can and cannot do, and how it differs from a sale and a purchase.

On this page

  • Definition
  • Rules
  • Taxes
  • Channels
  • Exchanges and the frequent-trading policy

Definition

An exchange moves money from one BobsFunds fund to another within the same account. It is a sale of the first fund and a purchase of the second, processed together at the same day's NAVs, so the money is never out of the market overnight.

Rules

  • Both funds must be in the same account. Moving money between two accounts (for example, from a taxable account to a Roth IRA) is not an exchange. See Exchange rules and limits.
  • The exchange is priced at both funds' NAVs for the trade date (that day if before 4:00 PM ET).
  • There is no fee and no minimum beyond $1.
  • An exchange can be for a dollar amount, a number of shares, or all shares of the "from" fund.
  • An exchange into a new fund opens a new position; an exchange into a fund already held adds to it.

Taxes

  • IRAs: an exchange has no tax effect.
  • Taxable accounts: an exchange is a sale and can create a capital gain or loss. See Tax effects of exchanges.

Channels

Online (Transactions → Exchange), mobile app, chat (see Procedure: Exchange Between Funds (chat)), or phone.

Exchanges and the frequent-trading policy

Exchanges count toward round trips. See Frequent trading (market timing) policy.
