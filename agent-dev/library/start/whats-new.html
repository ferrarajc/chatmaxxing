What's new in the library

Section: Start Here · Page ID: whats-new

Recent changes to products, rules, and procedures that agents should know about.

On this page

  • September 2026
  • Earlier in 2026
  • Annual changes to expect

September 2026

  • 2026 IRA limits are in effect: $7,500 base and a $1,100 catch-up at age 50 and older, for a total of $8,600. The Roth income phase-out ranges also rose. See IRA contribution limits and Roth IRA income limits.
  • The full 36-fund lineup is tradeable through chat. Earlier versions of some task scripts offered only the six original funds. Clients may buy, sell, exchange, and set up automatic investments in any fund in The BobsFunds lineup.
  • Cash balances are shown separately. An account's total value is its uninvested cash plus the value of its fund holdings. When a client funds a purchase from "cash in account", only the cash portion is available. See Funding sources for purchases.
  • IRA contributions summary. Account pages and the agent info panel show year-to-date IRA contributions against the client's limit, aggregated across all of the client's IRAs at Bob's. See The IRA contributions summary.
  • Client-submitted actions. Adding an authorized account user must be approved by the account owner in their own chat window. The agent's button reads "Send to client". See Actions the client must submit.

Earlier in 2026

  • The phone callback console launched for agents who handle scheduled callbacks. See The phone callback console.
  • Continue this chat. Clients who spoke with an agent in the last 7 days can continue that conversation, and the prior transcript loads into your column. See Continued chats.
  • Evidence highlighting on Proposed Action cards shows exactly where in the transcript each value came from. See Evidence highlighting.

Annual changes to expect

Every autumn the IRS publishes the next year's contribution limits and income ranges; the library is updated before January 1. Every December the next year's holiday calendar is published. The fund catalog changes whenever a fund is added or its prospectus is updated; fund profile pages update automatically.
