Exceptions to the early-withdrawal penalty

Section: IRA Distributions · Page ID: penalty-exceptions

The situations in which IRA withdrawals before 59½ avoid the 10% additional tax, with limits.

Exceptions that apply to employer plans but not IRAs

Clients sometimes confuse these. The "separation from service at 55" exception applies to 401(k) and similar plans, not IRAs. A client who rolls a 401(k) into an IRA at 56 loses that exception for the rolled money. Mention this neutrally if a client aged 55–59 is discussing a rollover and plans to withdraw.

What we do

We report most exception distributions with code 1, and the client claims the exception on their tax return. For disability, we can use code 3 with documentation, and for 72(t) plans, code 2. Do not tell a client they qualify for an exception; explain the list and suggest they confirm with a tax advisor.
