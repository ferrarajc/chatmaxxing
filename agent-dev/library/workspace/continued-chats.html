Continued chats

Section: Agent Workspace & Tools · Page ID: continued-chats

How "Continue this chat" works for clients and what you see when a client returns.

On this page

  • The client side
  • Your side
  • If you were not the original agent
  • Privacy
  • Example

The client side

If a client spoke with a live agent within the last 7 days, opening chat shows a card with the date and a one-sentence recap of that conversation and a Continue this chat button. Clicking it checks whether the same agent is available. The client can wait for that agent or take the first available agent.

Your side

When you accept a continued chat, the previous transcript loads into your column, marked as a continued conversation. Read the recap and skim the transcript. Open with continuity: "Welcome back, Maria. Last time we set up your monthly investment into BF500. How can I help today?"

If you were not the original agent

You inherit the previous agent's commitments. If they promised a follow-up, check whether it happened. Do not contradict a prior agent in front of the client; if you believe something was handled incorrectly, correct it calmly and note it in ACW.

Privacy

The recap is written in second person for the client ("You granted your wife limited access..."). It is shown only to the client in their authenticated session and to agents.

Example

The previous agent set up an automatic investment and promised to email a confirmation. When the client continues the chat, you check: the confirmation was sent. You open with: "Welcome back! I see you set up your $200 monthly investment last week; that confirmation went to your email on file. What can I help with today?"
