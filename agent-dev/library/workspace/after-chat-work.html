After-chat work (ACW)

Section: Agent Workspace & Tools · Page ID: after-chat-work

What the system writes for you when a chat ends, what you must review, and how to submit.

On this page

  • What is generated
  • What you must do
  • Timing
  • Example summary
  • Wrap-up code for that example

What is generated

When a chat ends, the column moves to after-chat work. The system automatically drafts:

  • A wrap-up code from the standard list. See Wrap-up codes.
  • A summary of three to five factual sentences: what the client asked, what was done, and the outcome.
  • Coaching: one sentence of specific positive feedback and, where useful, one actionable improvement point, written to you.

What you must do

Review and submit. You do not write ACW by hand, but you are responsible for it being correct:

  • Is the wrap-up code the most specific one that fits the main topic?
  • Does the summary accurately state what was done, including reference numbers and any promised follow-up?
  • If you promised a callback, a secure message, or a specialist contact, is it in the summary?

Edit anything that is wrong before submitting. Accurate summaries matter because the next agent, and the client's "Continue this chat" recap, depend on them.

Timing

Submit ACW promptly. A column in ACW is not available for a new contact. Aim to finish within one minute of the chat ending.

Example summary

"Client asked to add her daughter as a view-only user on her Roth IRA. Agent explained access levels; client chose View-only. Agent sent the action for client approval; client submitted (REF-48231). Daughter will receive an email invitation."

Wrap-up code for that example

Access Authorization.
